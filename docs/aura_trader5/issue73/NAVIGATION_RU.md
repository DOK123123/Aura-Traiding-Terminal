# Issue #73 · Aura Manual Trader 5.0 · мобильная навигация

Только изолированный Render Preview с `server_signals=True` получает новые
статические CSS/JS. Исходные расчёты, API и DOM-обработчики остаются прежними:
мобильный shell **переносит** существующие элементы, не клонируя их.

| Раздел | Содержимое |
| --- | --- |
| Главная | Реальные свежие Bitget BTCUSDT Bid/Ask или STALE; WAIT/WATCH, Entry, SL, TP, net RR, быстрые кнопки |
| Сигналы | Signal Confidence 50–100, исследовательские LONG/SHORT, объяснения/отмена, ручные уровни; раскрываемые дополнительные аналитики и WATCH-диагностика |
| График | Исходные свечи, LIVE-оверлей, таймфреймы, EMA, ручная разметка Entry/SL/TP/направления и индикаторы |
| Ещё | Локальный журнал Confidence/экспорт, тема, отдельный Manual Paper, исторический replay, проверка Preview |

Навигация снизу закреплена с учётом safe-area. Поддержаны клавиатура (стрелки,
Home/End, Tab), кнопки не меньше 44px, Back/Forward и прямые ссылки
`#app-home`, `#app-signals`, `#app-chart`, `#app-more`. Журнал доступен за два
касания: «Ещё» → раскрыть журнал.

Главная читает только существующий owner-protected GET
`/api/preview/signals/snapshot`; не создаёт новых записей/ордеров. LIVE
показывается только при правильном публичном источнике Bitget, работающем
наблюдателе, корректном серверном времени, спреде и Bid/Ask не старше 5 секунд.
Иначе STALE, Bid/Ask скрыты. WATCH только после полного
`Aura5Confidence.usable` с текущим порогом. Без WATCH — WAIT; CONFIRMED не
показывается. Балл 80/100 не означает 80% шанса прибыли. Render Free может
засыпать; уведомления и наблюдение в фоне не гарантируются.

Проверки: `tests/test_issue73_navigation.cjs`, `tests/test_issue73_page.py`,
`scripts/verify_issue73_browser.cjs` (desktop, Pixel 7, Samsung A50-совместимые
360px; вкладки, темы, навигация, свежесть/обрыв/восстановление, отсутствие POST),
все исходные регрессии. Браузерные цены — **fixtures, не котировки Bitget**.
В Issue #73 нет новых данных о торговом преимуществе.
