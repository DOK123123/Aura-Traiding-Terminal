# Issue #73 · отдельные проходы аудита

Проверка проведена отдельными проходами логики и безопасности. **Внешний
независимый рецензент не привлекался**; не приписываем себе чужую экспертизу.

1. **Изоляция:** shell включается только в owner-protected Signal Preview.
   Существующие `PAPER/Active43`, main и реальные ключи не изменяются.
   Новая часть использует только GET и не содержит вызовов исполнения.
2. **Источники:** для HOME используются исключительно свежие подтверждённые
   Bitget Bid/Ask. Неверная область, stopped observer, невалидный спред,
   просрочка или ошибка сети дают STALE. Исторические свечи не выдают LIVE.
3. **Риск:** исследовательские WATCH/WAIT не выдаются за CONFIRMED и не
   характеризуют вероятность прибыли. Entry/SL/TP и net RR берутся из
   неизменённой модели Confidence, отдельно оставлена ручная форма.
4. **Совместимость:** не создаются копии DOM с дублирующими ID. Исходные
   обработчики графика, звука, диагностик, виртуального счёта и экспорта
   сохраняются. Старые браузерные тесты адаптированы к вкладкам.
5. **UX:** `tablist`, `aria-selected`, focus-visible, касания ≥44px, safe-area,
   Back/Forward, светлая/тёмная тема и 360px viewport.

После первого зелёного Chromium CI просмотрены фактические скриншоты 360px и
Pixel 7. В светлой теме обнаружен недостаточный контраст предупреждения и
текста главной зелёной кнопки; оба цвета исправлены отдельным CSS-патчем.

Ограничения: Chromium эмулирует Android, физический Samsung не проверялся;
fixture-тесты не являются forward или replay рыночных сигналов. Render Free
может засыпать и не гарантирует уведомлений. Отдельный существующий виртуальный
Manual Paper требует собственных ручных действий; этот UI ничего не открывает.
