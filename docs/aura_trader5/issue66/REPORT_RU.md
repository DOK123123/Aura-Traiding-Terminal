# Aura 5.0 — Issue #66

## Реализовано

Отдельная диагностическая трассировка объясняет неизменённые BASE-правила шести семейств для LONG/SHORT на 5m/15m/1h/4h. Счётчики 24/48 часов считают действительно обработанные закрытые свечи, кандидатов, WATCH, REJECTED и причины. Каждая запись содержит UTC, источник, модель, закрытие свечи и доступный возраст Bid/Ask. Ошибки получения данных записываются отдельно от решений. Запись решения, входа и watermark атомарна; повтор одного закрытия не увеличивает счётчики.

В Aura 5.0 добавлен раздел «Почему сигналов нет», различающий OFFLINE, STALE, NO TRADE, UNVALIDATED и CONFIRMED. CONFIRMED по-прежнему требует VALIDATED в реестре. Порогов, формул, eligibility и исходного engine изменения не касаются.

Независимый WATCH-звук по умолчанию выключен. Есть явное предупреждение «НЕПРОВЕРЕННАЯ ГИПОТЕЗА, НЕ КОМАНДА НА СДЕЛКУ», активация жестом, направления, громкость, mute, контроль свежести/геометрии/источника и дедупликация после reconnect/reload и между вкладками через Web Locks. Исследовательская подготовка может уведомлять после opt-in, но перенос в ручную форму требует технического триггера. Новых POST, ордеров и обращений к приватному счёту нет.

Доставка и подтверждение учитываются только в этом браузере. «Доставлено» означает успешное планирование Web Audio, не доказанную слышимость. Сервер возвращает UNKNOWN для недоступных ему подтверждений. Закрытый браузер/заблокированный телефон не имеют гарантированной доставки. Без Web Locks или доступного локального хранилища автоматический WATCH-звук блокируется.

## Журнал и покрытие

SQLite содержит ограниченный 49 часами журнал решений и выборок; лимиты 100000/200000 строк. Неполная история и смена экземпляра журнала показаны явно. UUID журнала позволяет обнаружить потерю/замену БД, UUID сессии — перезапуск писателя. История до первого наблюдения — UNKNOWN_OR_LOST. Интервалы наблюдений процесса включают ошибки рынка и не являются доказательством непрерывной доступности котировок.

Экспорт UI содержит сводку, локальные уведомления и первые 20 серверных пакетов решений; признак full_server_journal сообщает об усечении. Полный доступный журнал выгружается owner-only GET `/api/preview/signals/journal?hours=48&kind=decisions&after=0&limit=1000`, затем с next_after до has_more=false; kind=samples выгружает выборки. Сервер не принимает подтверждения браузера. Экспорт исключает приватные данные счёта.
