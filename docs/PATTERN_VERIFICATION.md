# Проверка Historical Pattern Engine

Дата локальной проверки: 18 сентября 2026 (время рыночных событий на момент проверки — 17 сентября, около 22:50–23:00 UTC).

- Полный набор: **88 passed**. Единственное предупреждение — устаревший alias anyio в зависимости Starlette.
- 16 запросов анализа: XAUUSD/BTCUSDT × 1m/5m/15m/1h × контекст 500/2000, все HTTP 200. Получено по 5000 реальных свечей OANDA и 10 000 Binance на таймфрейм. Результаты сохранены в `pattern-check.json`.
- Для обоих инструментов выполнены исторический replay и walk-forward backtest по 10 точкам. При исходном similarity 75% совпадений не было: WAIT, нулевая оценка свидетельств, win rate/average return/PF не определены. Исходные параметры ради сигналов не подбирались.
- Для проверки таблиц и графика в браузере временно использован диагностический similarity 50%: XAUUSD 15m, контекст 500, 23 аналога, средняя similarity 61.39%; через 20 свечей UP 14/23 (60.87%), DOWN 9/23 (39.13%), среднее движение +0.14%, медиана +0.28%, MFE +0.57%, MAE −0.41%. Confidence 11.75%, сигнал WAIT. Это наблюдение конкретного момента, не постоянные значения интерфейса.
- Отдельный график аналога 2026-08-04 20:30 UTC открылся с маркером MATCH END. Live-график не заменяется. Клавиатурная активация ссылки также проверена.
- Историческая точка XAUUSD 2026-09-15 12:00 UTC показала POINT REPLAY и отдельно фактические исходы 5/10/20/50, исключённые из прогноза.
- В браузере выполнен backtest по пяти точкам XAUUSD: пять WAIT, отсутствие выдуманного win rate и доходности сделки при отсутствии сделок.
- Во время анализа BTC продолжал показывать LIVE, менялись текущая цена и volume. Поток XAUUSD также продолжил обновлять текущую свечу. Ошибок JavaScript не обнаружено.
- Проверены инвариантность к масштабу цены/объёма, отсутствие влияния изменённого будущего на сигнал, purging/разнесение аналогов, missing volume, точные MAE/MFE, обе ветви LONG/SHORT, низкая выборка, NO DATA, source isolation, расходы и max drawdown backtest. Искусственные данные находятся только в unit tests.
- Исправлена обнаруженная зависимость старого теста золота от перехода минуты: незакрытая свеча теперь создаётся непосредственно при выполнении теста.
- Архив размещён внутри проекта: `.cache/patterns.sqlite3`; соединения SQLite явно закрываются после операций.

Диагностические параметры в браузере возвращены к исходным. Тесты не доказывают прибыльность; следующая проверка стратегии должна использовать заранее зафиксированные параметры и отдельный вневыборочный период.
